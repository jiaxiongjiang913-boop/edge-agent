# 文献检索与题录整理

这是给当前 Agent 执行的流程模板，不会自行调用模型或宣称已经完成检索。

## 输入
研究主题与关键词（可中英双语）、年份范围、需要的篇数、纳入/排除条件、输出目录。
缺少决定范围的输入时先向用户确认；遵守当前电脑的数据盘和文件规则。

## 执行
1. 先读 `edge_status` 与 `edge_tabs`。已授权任务未连接时使用 `edge_start`；用户主动暂停时保持暂停。
2. 打开真实学术检索页面（例如 Google Scholar 或 X-MOL），读取快照，在搜索框输入关键词，点击搜索并逐页查看结果。不要用拼接搜索 URL 或单次接口结果冒充浏览过程。遇验证码交给用户。
3. 打开候选论文的正文/摘要页，按纳入条件筛选。进入出版方页面核对题名、作者、年份、期刊、DOI；记录实际读过的来源链接和访问日期。
4. DOI 规范化后去重；无 DOI 时用题名、第一作者和年份辅助去重。不推测作者、页码、DOI 或全文下载权限。
5. 需要全文时，只使用当前用户已有权限和页面实际提供的下载入口；用 `edge_download` 指定用户的数据盘目录，并确认完成。付费、无权限或只找到摘要时如实记录。
6. 每篇保留简短纳入依据；截图留证，输出可检索的题录表。用户需要时另出 BibTeX/RIS，缺失字段留空。

## 输出字段
`id,title,authors,year,journal,doi,source_url,accessed_at,inclusion_reason,fulltext_status,local_file`

另列检索站点、实际查询词、翻页范围、筛选规则和排除原因。区分“检索候选数”“已核对数”“已下载数”，不能把搜索摘要当作已读全文。

## 示例给 Agent 的指令
请按本模板检索【研究主题】在【年份范围】内的【篇数】篇论文，逐篇核对出版方页面，输出题录 CSV 与来源链接到【数据盘输出目录】。需要全文时仅使用我已有的访问权限。
